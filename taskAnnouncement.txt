Task Description
Input: A Bangla programming prompt
Output: A Python script that satisfies all hidden unit tests

Column	Description
id	id
instruction	Bangla prompt (e.g., দুটি পূর্ণসংখ্যার গ.সা.গু নির্ণয় করো)
response	Reference Python solution†
test_cases	Hidden tests (JSON list of I/O pairs)
Note: † present only in the Train file

Example Row (Train)
📋
id, instruction,response,test_cases
"1",
"দুটি পূর্ণসংখ্যার যোগফল নির্ণয় করো",
"import sys;a,b=map(int,sys.stdin.read().split());print(a+b)",
"[['2 3','5'],['10 20','30']]"
